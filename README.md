# Camunda Lab

Projeto de laboratório para aprender e desenvolver processos com Camunda 8, Spring Boot e Java 21.

## Tecnologias

- Java 21
- Spring Boot 3
- Maven
- Camunda 8 SDK
- Git/GitHub

## Objetivo

Criar processos BPMN pequenos, executar workers em Java e testar a integração com Camunda 8.

## Como correr

```bash
./mvnw spring-boot:run
```

No Windows:

```bash
mvnw.cmd spring-boot:run
```
